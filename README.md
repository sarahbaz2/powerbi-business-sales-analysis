📌 Overview

This project presents an end-to-end **Power BI dashboard** analyzing business performance across **sales, customers, time, and store operations**.

The goal of this project is to transform raw transactional data into **actionable insights** through data cleaning, modeling, and interactive visualization.

---

🧠 Tools & Skills

- Microsoft Power BI  
- Power Query (ETL)  
- Data Modeling (Star Schema)  
- Data Visualization  
- Business Analysis

📈 Key Insights

- Revenue increased significantly from **2007 to 2008**
- Peak performance occurred in **early 2009**, followed by stabilization  
- A small number of customers generate a **large portion of total revenue**
- **Mid-income customers** contribute the most to sales  
- **Supermarkets outperform** other store types  
- Sales are geographically concentrated across key regions  

---

🔍 Features

- Interactive filters (date, customer, store, product)
- Dynamic dashboard navigation
- KPI tracking (Revenue, Quantity, Customers, Transactions)
- Toggle between Revenue and Quantity views
- Cross-filtering between visuals
